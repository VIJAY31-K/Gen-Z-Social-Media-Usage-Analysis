Gen-Z Social Media Usage Analysis Dashboard
📌 Overview

The Gen-Z Social Media Usage Analysis Dashboard is an end-to-end data analytics project designed to analyze social media engagement patterns, screen-time behavior, addiction levels, and mental health insights among Gen-Z users.

This project combines data preprocessing, SQL querying, exploratory data analysis (EDA), and interactive dashboard visualization to generate meaningful insights from social media usage data.

The project was developed using:

Excel for initial data cleaning
Python for EDA and analysis
PostgreSQL/MySQL for database operations
Power BI for dashboard creation and KPI reporting
DAX for custom measures and analytics
📂 Dataset

The dataset contains information related to:

User demographics
Daily screen time
Session duration
Platform usage
Addiction levels
Mental health scores
Social media behavior patterns

📈 Key Insights
Instagram was the most used platform among Gen-Z users.
Higher screen time was associated with lower mental health scores.
Medium addiction users formed the largest user category.
Young Adults and Working Gen-Z showed higher engagement patterns.
Entertainment was the primary reason for social media usage.
